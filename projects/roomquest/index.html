RoomQuest.

Find the room, then find the route. Interactive campus maps with shortest-path navigation between classrooms and facilities.

The question

Finding a classroom in an unfamiliar building is a spatial problem. The interface needs to connect a room name with a route people can follow.

The approach

A React and TypeScript interface combines an interactive SVG map, points of interest, and route details. A Dijkstra implementation with a priority queue computes paths through the campus graph. Local JSON data supports map exploration. The repository retains an OpenIndoorMaps/PathPal sample interface and map; the capture shows that example rather than a surveyed campus deployment.

The result

A campus-navigation prototype with implemented pathfinding and map interaction. Earlier BLE experiments are distinct from the route-planning interface shown here; deployed indoor positioning is not claimed.
