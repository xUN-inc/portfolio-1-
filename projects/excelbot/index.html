The question

Spreadsheet requests are often expressed in everyday language, while reliable workbook changes need explicit, repeatable operations.

The approach

An Electron and React interface connects to FastAPI and a local Ollama planner. A registry of Python tools performs workbook operations with openpyxl; SQLite keeps conversation history. The interface separates a proposed plan from the user’s decision to execute it.

The result

A local assistant with implemented merge, comparison, formatting, formula, and validation tools. Focused workbook tests exist in the source. The portfolio preview shows the original interface; it does not imply every model or arbitrary automation path has been validated.
