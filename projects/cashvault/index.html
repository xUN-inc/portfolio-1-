The question

Cash has no automatic transaction feed. Keeping track of notes, coins, spending, and money owed calls for a lightweight tool that works without a network.

The approach

Flutter screens bring balances, income, expenses, and transaction history together. Local Hive storage supports offline use; the project also includes debt tracking, reminders, and CSV export.

The result

A mobile utility focused on everyday money organization. The public app code includes transaction entry, cash inventory, and local reporting. Optional Firebase scaffolding is separate from its local-first core.
