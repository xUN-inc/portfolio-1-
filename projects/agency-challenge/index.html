The question

Financial tables can hide relationships across organizations. How can an investigator explore funding loops, trace the source data, and decide what needs closer review?

The approach

A SQL-backed Node service surfaces funding loops from CRA T3010 data. The original interface uses D3 network graphs alongside organization details, spending context, and generated investigation memos. Related challenge repositories explore a shared analytics interface and investigation backend.

The result

An investigation-support prototype that connects database queries, graph visualization, and written analysis. A loop is a lead to examine, not proof of wrongdoing; source context and human review remain essential.
